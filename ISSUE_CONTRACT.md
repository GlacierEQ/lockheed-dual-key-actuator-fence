# ISSUE CONTRACT

## Pain
Single-process "assurance" demos often let the same object decide and actuate, so a bug or compromised path both approves and fires.

## Non-goals
- Real weapons, classified systems, or operational mission software
- Distributed consensus across data centers (single-process correctness first)

## Success
- Dual-key requirement enforced in code
- Expired grants refuse
- Input digest mismatch refuses
- Receipts are deterministic for identical inputs
